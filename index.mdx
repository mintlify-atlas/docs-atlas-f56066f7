Inkfinite is a local-first infinite canvas that runs in your browser and as a native desktop app. Draw diagrams, wireframes, and sketches using a shared document model backed by Automerge — every edit is validated, history is preserved, and files can be inspected, scripted, and rendered from the command line.

## Get Up and Running

<Steps>
  <Step title="Open the editor">
    Open the [web editor](https://inkfinite.app) for an instant browser-based canvas, or install the desktop app for native file support. Read the [Web platform guide](/platforms/web) for storage details.
  </Step>
  <Step title="Create a board">
    Choose **New board** from the board browser. Draw shapes with the toolbar, connect them with arrows, and use **Layout** to arrange them.
  </Step>
  <Step title="Save or export">
    Browser boards save automatically. In the desktop app, choose **Save As** to create a `.inkfinite` file. Export SVG, PNG, or Excalidraw when you need to share with other tools.
  </Step>
  <Step title="Automate with the CLI">
    Install `inkfinite` from [GitHub Releases](https://github.com/stormlightlabs/inkfinite/releases) or via `cargo install inkfinite-cli --locked`. Use `inkfinite inspect`, `query`, `shape`, and `render` to work with documents from scripts and agents.
  </Step>
</Steps>
