Inkfinite exposes shortcuts for every common action so you can keep both hands on the keyboard while designing, wireframing, or diagramming. The tables below cover all three categories — selection and editing, order and canvas, and application-level commands. On macOS, use **Cmd** where the table shows **Cmd/Ctrl**; on Windows and Linux, use **Ctrl**.

<Tip>
  Press **?** anywhere in the editor to open the searchable shortcut panel. It lists every shortcut and updates dynamically as new commands are added.
</Tip>

## Selection and Editing

These shortcuts operate on the current selection or the canvas as a whole. Duplicate and Connect is particularly useful when building diagrams — it clones the selected shape and immediately adds a bound arrow between the original and the copy.

| Action | Shortcut |
| --- | --- |
| Select all | Cmd/Ctrl+A |
| Clear selection or leave a container | Escape |
| Copy, cut, paste | Cmd/Ctrl+C, X, V |
| Duplicate | Cmd/Ctrl+D |
| Duplicate and connect | Option+Cmd / Alt+Ctrl+D |
| Group | Cmd/Ctrl+G |
| Ungroup | Shift+Cmd/Ctrl+G |
| Lock selection | Shift+Cmd/Ctrl+L |
| Nudge | Arrow keys |
| Nudge 10 pixels | Shift+Arrow keys |
| Undo | Cmd/Ctrl+Z |
| Redo | Shift+Cmd/Ctrl+Z or Cmd/Ctrl+Y |

## Order and Canvas

Use these shortcuts to adjust the stacking order of objects or to navigate the infinite canvas itself. **Fit drawing** zooms to show all objects on the current page; **Fit selection** zooms to the currently selected objects.

| Action | Shortcut |
| --- | --- |
| Bring forward / send backward | Cmd/Ctrl+] / [ |
| Bring to front / send to back | Shift+Cmd/Ctrl+] / [ |
| Pan | Space+drag |
| Zoom in / out | + / − |
| Fit drawing | Shift+1 |
| Fit selection | Shift+2 |

## Application

Application-level commands open panels and overlays without interrupting the active canvas state.

| Action | Shortcut |
| --- | --- |
| Open boards | Cmd/Ctrl+B |
| Open command palette | Cmd/Ctrl+K |
| Show shortcuts | ? |

<Note>
  Right-click the canvas or a selection to see a context menu with commands specific to what is under the cursor. Many actions that don't have dedicated shortcuts appear there.
</Note>
